TL;DR

Problem
The Innovation Gridlock
25+ teams were each inventing their own AI patterns. No shared language, no governance, no way to tell a trustworthy interaction from a risky one. Every team rebuilt the same wheel, and compute costs ballooned with the most expensive pattern as the default.
Solution
A 5-Pattern Taxonomy
I defined five AI interaction patterns — from fully embedded to fully agentic — each with clear governance, trust requirements, and a cost profile. Teams could now place any feature on the map and know exactly how to build it.
Outcome
One Language, 25+ Teams
The taxonomy became the shared standard. Embedded AI as the default drove a 2,000× reduction in compute cost, and the work secured a company-level Strategic Growth Objective.

Key Features

The Pattern Map

Five patterns, one axis: how much autonomy the system has. Each pattern carries its own trust contract and cost profile, so a team picks the cheapest pattern that solves the problem rather than defaulting to the most expensive.

The 5-pattern taxonomy diagram, embedded → agentic

The Glass Box

Trust in AI comes from visibility. The Glass Box pattern makes the system's reasoning legible at the moment of action — what it's doing, why, and how to intervene. It became Workday's governance standard for agentic AI.

Glass Box interaction: reasoning surfaced inline with intervention controls

Governance That Travels

The system isn't a static doc — it's decision logic teams run themselves. Each pattern ships with the criteria to know when it applies, so governance scales without a central bottleneck.

Governance decision tree teams use to self-classify features

Deep Dive

The Cost ArgumentHow a design decision became a 2,000× compute story

The default was the problem

Most teams reached for the most capable, most expensive pattern by reflex. The taxonomy reframed the choice: start from the cheapest pattern that meets the trust bar, escalate only when the problem demands it.

Why it stuck

Engineers adopted it because it made their lives easier, not because leadership mandated it. The logic was self-serve.

ReflectionScaling yourself through a system

What worked

Shipping decision logic instead of a style guide. Teams didn't need me in the room to make the right call.

What I'd refine

Earlier socialization with engineering leadership — the patterns were sound before they were political, and the political work lagged.
